## 🧠 What I'm doing right now

I'm building a **code review agent with memory** — an LLM-based reviewer that doesn't just diff your PR, it remembers your codebase's conventions, past review comments, and architectural decisions across sessions. It's my main portfolio piece for fall internship applications, and the part I'm most excited to talk about in interviews: retrieval, context-window tradeoffs, and how you actually evaluate whether an LLM's judgment is *good*.

```
🔍 review request → 🧵 pull relevant history/context (RAG) → 🧠 reason over diff + memory → 💬 structured feedback
```
